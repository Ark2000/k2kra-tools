# k2kra-tools

Minimal, practical little tools built with AI. Each tool lives in its own folder and builds on its own.

| Tool | What it does | Platform |
|---|---|---|
| [sticky-editor](sticky-editor) | Open any text file as a floating sticky note, with Markdown preview | Windows |
| [vivo-notes](vivo-notes) | Pull all vivo Office Suite notes to local Markdown files | Windows |
